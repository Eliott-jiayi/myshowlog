在添加剧集/书籍时点「AI 智能识别」上传海报/封面，自动识别名称、集数、标签并填入。API Key 仅存本机 localStorage，不上传服务器。

获取 Gemini Key：打开 aistudio.google.com → 创建 API Key（免费额度充足）。Key 仅用于浏览器直接调用，请妥善保管。

数据备份

导出当前账号所有剧集、书籍、记录、自定义应用到 JSON 文件，可换设备导入恢复。

关于

MyShowLog · 纯前端单页应用，剧集与书架两个独立模块，数据保存在浏览器 localStorage 与 IndexedDB，按账号隔离。

注销账号

注销将永久删除本机上该账号的全部数据（剧集、书架、记录、头像、应用设置、图库图片），且不可恢复。请谨慎操作。
